## Анализ факторов виральности статей

Командный учебный проект. Исследование того, какие факторы связаны с числом
репостов статей, методами проверки статистических гипотез

## Данные
Датасет Online News Popularity (Kaggle) — статьи медиа Mashable
(технологии, цифровая культура, соцсети). Источник: kaggle

## Задача
Определить, какие факторы (день публикации, количество ссылок, тематика)
статистически значимо связаны с числом репостов

## Что сделано
- Разведочный анализ: распределение репостов, разбивка по тематикам, дням,
  числу ссылок, тональности
- Проверка нормальности через Q-Q графики и осознанный выбор критерия
- Проверка гипотез: тест Манна–Уитни (выходные vs будни), t-тест
  (много ссылок vs мало), z-тест (Social Media vs Business)
- Формулировка H0/H1, интерпретация p-value, выводы по каждой гипотезе

## Основные выводы
- Статьи, опубликованные в выходные, получают значимо больше репостов
- Статьи с большим числом ссылок получают больше репостов
- Категория Social Media виральнее категории Business
